# Four Blinking LEDs

## Description
Expands the first GPIO exercise by controlling four external LEDs together from four output pins.

## Hardware
- Arduino Uno R3 (ATmega328P)
- 4 LEDs
- 4 x 330 ohm resistors
- Breadboard and jumper wires

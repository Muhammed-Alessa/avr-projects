# Pushbutton with Internal Pull-Up

## Description
Uses the ATmega328P internal pull-up resistor so a pushbutton can be read without an external pull-up resistor.

## Hardware
- Arduino Uno R3 (ATmega328P)
- Pushbutton
- Breadboard and jumper wires

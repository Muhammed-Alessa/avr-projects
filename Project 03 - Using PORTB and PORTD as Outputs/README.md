# Using PORTB and PORTD as Outputs

## Description
Demonstrates writing patterns to groups of ATmega328P GPIO pins. The original book exercise used PORTA and PORTB; the Uno adaptation uses PORTB and PORTD because the ATmega328P has no PORTA.

## Hardware
- Arduino Uno R3 (ATmega328P)
- 12 LEDs
- 12 x 330 ohm resistors
- Breadboard and jumper wires

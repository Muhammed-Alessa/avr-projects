# External Interrupt INT0

## Description
Keeps the main program blinking one LED while a pushbutton on INT0 independently toggles another LED inside an interrupt service routine.

## Hardware
- Arduino Uno R3 (ATmega328P)
- Pushbutton
- External LED
- 330 ohm resistor
- Breadboard and jumper wires

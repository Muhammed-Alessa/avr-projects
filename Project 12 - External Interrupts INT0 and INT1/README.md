# External Interrupts INT0 and INT1

## Description
Uses both external interrupt inputs on the ATmega328P. Each pushbutton toggles a different LED.

## Hardware
- Arduino Uno R3 (ATmega328P)
- 2 pushbuttons
- 2 LEDs
- 2 x 330 ohm resistors
- Breadboard and jumper wires

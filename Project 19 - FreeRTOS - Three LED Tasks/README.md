# FreeRTOS - Three LED Tasks

## Description
Creates three FreeRTOS tasks that blink three LEDs at different rates, adapting the book's final RTOS exercise to the ATmega328P used on the Arduino Uno.

## Hardware
- Arduino Uno R3 (ATmega328P)
- 3 LEDs
- 3 x 330 ohm resistors
- FreeRTOS AVR port/source files

# DC Motor Direction Control

## Description
Controls the direction of a small DC motor through two logic inputs of a low-voltage H-bridge driver.

## Hardware
- Arduino Uno R3 (ATmega328P)
- Small low-voltage DC motor
- H-bridge motor-driver module
- External motor supply
- Jumper wires

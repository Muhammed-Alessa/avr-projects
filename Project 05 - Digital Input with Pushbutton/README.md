# Digital Input with Pushbutton

## Description
Reads a pushbutton as a digital input and uses its state to control the built-in LED.

## Hardware
- Arduino Uno R3 (ATmega328P)
- Pushbutton
- 10 kohm resistor
- Breadboard and jumper wires

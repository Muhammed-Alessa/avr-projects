# Three Buttons and Three LEDs

## Description
Uses three internally pulled-up inputs to control three LED outputs, demonstrating multiple digital inputs and outputs.

## Hardware
- Arduino Uno R3 (ATmega328P)
- 3 pushbuttons
- 3 LEDs
- 3 x 330 ohm resistors
- Breadboard and jumper wires

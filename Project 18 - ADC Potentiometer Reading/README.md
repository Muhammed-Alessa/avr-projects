# ADC Potentiometer Reading

## Description
Reads a potentiometer on ADC1 (Arduino A1) and displays an 8-bit version of the ADC result on eight LEDs.

## Hardware
- Arduino Uno R3 (ATmega328P)
- 10 kohm potentiometer
- 8 LEDs
- 8 x 330 ohm resistors
- Breadboard and jumper wires

# 7-Segment LED Counter

## Description
Drives a single common-cathode 7-segment display directly from AVR GPIO and counts from 0 to 9.

## Hardware
- Arduino Uno R3 (ATmega328P)
- 1-digit common-cathode 7-segment display
- 7 x 330 ohm resistors
- Breadboard and jumper wires
